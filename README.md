# VenueAlign

A static, responsive tour-production SaaS concept with a fictional Venue Fit workbench and local reviewer actions.

## Run

Serve the public directory with `python3 -m http.server 8080 --directory public`. Open localhost on port 8080. No build step, environment variables or third-party services are required to use the preview. Images, scripts, fonts and license notices are bundled.

## Edit and deploy

The editable website is in `public/`. Shared marketing layouts, product copy and original product diagrams are generated by `src/build.py`, `src/content.py`, and `src/scenic.py`. To refresh generated pages, install Pillow in a Python 3 environment and run `python3 src/build.py public`. The selected direction and component references are in [The Scenic Model](docs/scenic-design.md). The approved House Fold SVGs are in `public/assets/brand/`. The workbench, CRM, styles, scripts and evidence assets are authored directly. For static hosting, set the output directory to `public` and leave build and install commands empty.

## Browser verification

Run the Browser review workflow manually in GitHub Actions. It checks all page widths, exercises the local approval/export path and downloads a sample pilot brief with synthetic data. The artifact includes full-page desktop and mobile case captures. The independent Reference study workflow records position-based observations on three public design references.

## Boundaries

The example documents and all organizations and people in the walk-through are fictional. A real reviewer must decide equipment fit, staffing and physical setup. Proposed pricing and module availability remain hypotheses. Forms download a local draft. Live CRM/email delivery, authentication, document processing, integrations and hosted analytics require separate implementation. The demo event list contains names and timestamps only. The privacy page clears local events and reviewer state.

For a custom domain, use the owner-approved VenueAlign domain and the DNS records returned by the chosen host. The old StageRigfolio domain is unverified for this brand.
